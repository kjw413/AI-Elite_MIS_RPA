4. 비밀정보와 운영 안전

강제 적용

  • 녹화는 선택한 대상 창에서만 유효
  • 암호 필드 입력값은 기록하지 않음
  • Windows Credential Manager 참조만 workflow에 저장
  • 구조화 로그에 키 입력 원문·클립보드 본문 미기록
  • 실패 스크린샷은 지정 민감 영역을 마스킹
  • 전역 비상 중지 단축키는 workflow에 기록하지 않음

지원하지 않음

  • Windows 잠금·RDP 종료 상태 실행
  • UAC 보안 데스크톱 조작
  • MFA·CAPTCHA 우회
  • JSON에 비밀번호·토큰 평문 저장
  • workflow 안에서 임의 Python·PowerShell 실행
  • 검증 없이 좌표 클릭 계속 진행
