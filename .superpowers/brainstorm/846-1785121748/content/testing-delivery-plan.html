3. MVP 완료 기준

사용자가 할 수 있어야 함

  • 한 앱에서 대상 창 선택 → 녹화 → 편집 → 테스트 → 실행
  • 마우스와 키보드 입력을 의미 있는 단계로 확인
  • 날짜·텍스트를 실행 변수 또는 Excel/CSV 열로 지정
  • 최대 2단계 반복으로 조회·복사·Excel/CSV 저장
  • 실패 원인을 보고 마지막 성공 행부터 재개
  • JSON을 직접 열거나 LLM에 질문하지 않고 업무 구성

자동 검증되어야 함

  • UIA 우선, 환경 일치 시에만 상대좌표 fallback
  • 고정 키와 변동 텍스트가 별도 액션으로 저장
  • 로그·workflow·스크린샷에 비밀값이 없음
  • 검증 실패 시 출력 파일을 정상 파일로 교체하지 않음
  • 모든 테스트가 부모 프로젝트 import 없이 통과
  • Windows 10/11 x64에서 패키징된 앱 실행
